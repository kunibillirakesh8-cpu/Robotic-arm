Forward Kinematics

Forward Kinematics calculates the position of the robot's end effector from known joint angles and link lengths.

x = L₁cos θ₁ + L₂cos(θ₁+θ₂) + L₃cos(θ₁+θ₂+θ₃)
y = L₁sin θ₁ + L₂sin(θ₁+θ₂) + L₃sin(θ₁+θ₂+θ₃)

Each joint frame uses the homogeneous transformation (rotation about Z, then a move of one link length along the new X axis):

Tᵢ = [ cosθ −sinθ 0 L·cosθ ; sinθ cosθ 0 L·sinθ ; 0 0 1 0 ; 0 0 0 1 ]
Why this formula? Each link points at the sum of all earlier joint angles, so we add each link's x and y part.

Transformation matrices

Final matrix T₀₃ = T₀₁ × T₁₂ × T₂₃. The last column is the end-effector position.

About Project

This project demonstrates how trigonometry, matrices, coordinate geometry and transformation matrices determine the position of a robotic arm.

Problem: Given link lengths and joint angles, determine the position and orientation of the end effector.

Concepts: Trigonometry, Coordinate Geometry, Matrices, Matrix Multiplication, Homogeneous Transformation, Forward & Inverse Kinematics.

Applications: Industrial robots, manufacturing, pick-and-place, automation, CNC machines, robotic surgery, space robotics.
